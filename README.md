# 학점 계산기 (gpa-calculator)

Python/FastAPI와 HTML/CSS/JavaScript로 만든 한국어 학점 계산 웹앱입니다.
브라우저는 과목 정보를 서버에 보내고, **서버에서 계산한 결과**를 표시합니다.
4.5·4.3 만점 선택, 과목 추가·삭제, 평균평점과 반영 학점 표시, 성적표 확인을 지원합니다.
로그인·데이터베이스·외부 유료 API는 사용하지 않습니다. 특정 대학의 공식 계산기가 아닙니다.
입력 내용을 저장하지 않으므로 새로고침하면 초기화됩니다.

├── requirements.txt         # 실행 및 테스트 패키지의 검증된 버전

## 계산 기준

**평균평점 = Σ(학점 × 성적 점수) ÷ 평점 반영 학점의 합**

| 성적 | 4.5 만점 | 4.3 만점 |
| --- | ---: | ---: |
| A+ | 4.5 | 4.3 |
| A0 | 4.0 | 4.0 |
| A- | 사용 불가 | 3.7 |
| B+ | 3.5 | 3.3 |
| B0 | 3.0 | 3.0 |
| B- | 사용 불가 | 2.7 |
| C+ | 2.5 | 2.3 |
| C0 | 2.0 | 2.0 |
| C- | 사용 불가 | 1.7 |
| D+ | 1.5 | 1.3 |
| D0 | 1.0 | 1.0 |
| D- | 사용 불가 | 0.7 |
| F | 0 | 0 |
| P | 계산에서 제외 | 계산에서 제외 |

- **P**: 분자와 분모에서 모두 제외합니다.
- **F**: 성적 점수는 0이며 해당 학점은 분모에 포함합니다. 모두 F라면 `0.00`입니다.
- 과목이 없거나 모두 P이면 **계산 대상 없음**, 반영 학점은 `0`입니다.
- Python `Decimal`로 계산하고, 최종 평균에만 `ROUND_HALF_UP`을 적용합니다. 예를 들어 `4.125 → 4.13`입니다.
- 만점 기준 변경 시 A-처럼 사용할 수 없어진 성적은 선택을 비우고 재선택을 안내합니다. 유효한 성적은 유지합니다.
- 입력을 수정하면 이전 결과를 지우므로 계산 버튼을 다시 눌러야 합니다.

입력 규칙: 과목명은 앞뒤 공백 제거 후 1~100자, 학점은 **0 초과~100 이하이며 소수 둘째 자리까지**, 과목은 최대 1,000개입니다.
학점·성적·과목명 누락, 잘못된 숫자, NaN·무한대·참/거짓, 만점 기준에 없는 성적은 한국어 오류로 안내합니다.
빈 행은 자동으로 무시하지 않습니다. 사용하지 않는 행은 삭제하세요. P 과목도 입력값 검증을 받습니다.

## API

- `GET /`: 웹 화면
- `GET /api/grades`: 두 만점 기준의 성적 점수표 (`P`는 `null`)
- `POST /api/calculate`: 입력을 검증하고 계산 결과 반환
- `GET /docs`: 자동 생성된 API 설명 및 요청 실행 화면

요청 예시:

```json
{
  "scale": "4.5",
  "courses": [
    {"name": "프로그래밍", "credits": "3", "grade": "A+"},
    {"name": "글쓰기", "credits": "1", "grade": "B0"}
  ]
}
```

성공 응답:

```json
{"average":"4.13","included_credits":"4","status":"ok","message":"계산 완료"}
```

평균평점과 반영 학점은 표시 정밀도를 유지하기 위해 문자열로 반환합니다.
계산 대상이 없으면 `average`는 `null`, `status`는 `empty`입니다.
잘못된 입력에는 HTTP 422와 `message`, `errors`를 반환합니다.
`errors`의 각 항목에는 `row`(1부터 시작하는 과목 순서), `field`, 한국어 `message`가 있습니다.

## 검증

서버를 따로 실행하지 않아도 다음 명령으로 계산 로직과 API를 테스트할 수 있습니다.

```bash
cd /Users/parkjehyuk/Documents/Codex/gpa-calculator
source .venv/bin/activate
python -m pytest -q
```

자동 테스트 72개가 통과했습니다. 주요 확인 항목은 다음과 같습니다.

| 조건 | 평균평점 | 반영 학점 |
| --- | --- | --- |
| 4.5 기준, 3학점 A+ + 1학점 B0 | 4.13 | 4 |
| 4.5 기준, 3학점 A+ + 3학점 F | 2.25 | 6 |
| 첫 번째 예제에 9학점 P 추가 | 4.13 | 4 |
| 모든 과목이 P / 과목 없음 | 계산 대상 없음 | 0 |
| 모든 과목이 F (3학점) | 0.00 | 3 |
| 4.3 기준, 3학점 A- | 3.70 | 3 |

두 기준의 모든 성적, 소수 학점, 중간 반올림 방지, 성적표 API, 만점 변경 후 유효하지 않은 성적,
0·음수·비정상 학점, 필수값 누락, 잘못된 JSON과 정적 파일 응답도 확인합니다.
별도로 임시 Uvicorn 서버를 실행해 실제 HTTP로 HTML·CSS·JavaScript·성적표·OpenAPI 응답,
`4.13` 계산 결과와 잘못된 학점의 한국어 422 오류를 확인했습니다. 테스트용 서버는 종료했습니다.
JavaScript 문법 검사(`node --check static/app.js`)와 패키지 의존성 검사(`python -m pip check`)도 통과했습니다.
현재 Starlette TestClient에서 httpx 사용에 대한 지원 종료 예정 경고 1개가 나오지만 테스트 실패는 아닙니다.
테스트 방식은 [FastAPI 공식 테스트 안내](https://fastapi.tiangolo.com/tutorial/testing/),
검증 오류 처리는 [공식 오류 처리 안내](https://fastapi.tiangolo.com/tutorial/handling-errors/)를 참고했습니다.

사용자가 로컬 서버를 직접 실행해 **웹 화면과 계산 결과를 확인했습니다.** 개발 에이전트는 화면·앱·브라우저에 접근하지 않았으며, 모바일 표시와 세부 조작에 대한 별도의 브라우저 검증은 수행하지 않았습니다.
다시 확인할 때는 서버를 실행한 뒤 다음 순서로 확인하세요.

1. 두 과목에 이름과 `3 / A+`, `1 / B0`를 넣고 계산하면 `4.13`, `4 학점`이 표시되는지 확인합니다.
2. 과목 추가·삭제와 P/F 계산을 확인합니다. 모든 행을 삭제하고 계산하면 ‘계산 대상 없음’입니다.
3. 4.3 기준에서 A-를 선택한 뒤 4.5로 변경하면 재선택 안내가 나오고 성적 선택이 비워지는지 확인합니다.
4. 학점에 0이나 음수를 입력하거나 성적을 비우고 계산하면 한국어 오류가 표시되는지 확인합니다.
5. 창 폭을 줄여 모바일 레이아웃을 확인하고, Tab 키로 입력칸과 버튼을 이동해 봅니다.
